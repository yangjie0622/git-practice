# git-practice

我的第一个 GitHub 练手仓库，用来跑通「本地修改 → 提交 → 推送」这条链路。

## 这个仓库里有什么

| 文件 | 作用 |
|---|---|
| `README.md` | 项目说明，GitHub 上自动渲染成仓库首页 |
| `hello.txt` | 随便改的练习用文本文件 |
| `notes/git-commands.md` | 常用命令速查 |
| `.gitignore` | 声明哪些文件不进入版本管理 |

## 三条日常命令

```bash
git status              # 我现在在什么状态
git add . && git commit -m "改了什么"
git push
```
